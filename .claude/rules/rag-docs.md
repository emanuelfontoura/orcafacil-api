# Documentos do RAG

- Todo documento tem o frontmatter completo de `docs/README.md` §5.1.
- Ao editar, atualize `last_reviewed` no frontmatter e a data de "Última revisão" no cabeçalho.
- `sources` é relativo à raiz do repositório; `related` é relativo a `docs/`.
- Mudou uma regra obrigatória (`docs/README.md` §2)? Atualize também a rule correspondente em `.claude/rules/`.
